VIP Connect External Campaigns

Outbound dialing orchestration platform built on Amazon Connect Campaigns V2, Customer Profiles, and DynamoDB. Operators configure multi-bucket campaign plans through a React admin UI; an EventBridge-driven Lambda tick loop creates segments, starts campaigns, cascades DAG dependencies, and hard-stops every workload at 19:00 Colombia Time. HIPAA-compliant: PHI never enters logs or plan state.
